# 完成学会用 AI Agent Desktop App 全部课程

## 1. 目标

读完本课程全部 Task, 要建立起的是一套完整的, 能立刻上手的 AI Agent Desktop App 使用能力: 知道该选哪一款, 能独立办好账号, 认全界面上每一个真正影响体验的开关, 让它替你读写文件, 用上一个 Agent Skill, 并学会一套同时带几个 session 干活的心法, 而不是只停留在偶尔问它一句话的水平. 走到最后, 你还应该知道这门课停在哪儿, 以及想再往前该往哪走.

---

## 2. 要做的事情

1. 先读根目录的 README, 明白这门课怎么读.
2. 进 examples, 从 01 开始按编号往下读, 第一篇会给你整门课的地图.
3. 每篇先读 README 再照它自己的 TICKET 逐项做完并确认.
4. 走到讲具体工具那一块时, 只读你选定的那一款对应的那一篇, 另外两篇直接跳过.
5. 读完最后那个收尾 Task, 想清楚自己学到了什么, 以及下一步可以往哪走.

**预计用时:** 243 到 395 分钟 (约 4 到 6.5 小时)

---

## 3. 检查清单

- [ ] **全部 Task 完成**: examples 下每个 Task 的 TICKET 检查清单都已逐项打勾.
- [ ] **能独立复现**: 不看教程, 能把这门课的核心流程 (选工具, 办账号, 用界面干活, 用上 Agent Skill) 从头独立走一遍.
- [ ] **能讲清概念**: 能用自己的话解释基座模型, ChatBot, Agent 这套骨架, 以及这类 Agent App 共有的那八件事各自是什么.
- [ ] **知道下一步往哪走**: 能说出想再往前走有哪几个方向, 也知道最关键的那条是在 AI 的辅助下读官方文档原文.

---

## 4. 关键能力

- 能说清基座模型, ChatBot, Agent 这套骨架, 以及你付的钱到底买的是什么.
- 能按自己的所在地区与职业目标, 在 Claude Code, Codex, Antigravity 三款里选定要学的那一款, 并把账号免费办好.
- 能给一款 Agent App 绑定工作文件夹和 GitHub Repo, 把权限模式调到合适的档位, 并用文件浏览器确认它真的动了哪些文件.
- 能用截图, 文件路径, 右键挂载三种方式把材料交给 AI, 让它把产出写到指定位置, 并在不离开 App 的情况下审阅改动.
- 能召唤一个 Agent Skill 完成任务, 理解它是一套全世界统一的标准, 换任何一款工具用法基本不变.
- 能看懂 session, chat, 上下文这套记忆模型, 知道界面上看不见的东西同样在吃上下文, 并用 Fork 保住一份干净的上下文.
- 能按活儿的难度调整模型和 Effort, 明白自己付的钱花在了哪个档位上.
- 能在开工前把目标和步骤写进一份计划文档, 分清探索型与执行审阅型任务, 并同时开几个 session 并行推进.
- 能说出这类 Agent App 跨工具通用的那八件共性, 换任何一款新工具都知道该先看什么.
