# 学会用 AI Agent Desktop App 总览

> 一句话: 这门课教你从零选定并用熟一款 AI Agent Desktop App, 让它真正替你干活. 想先了解全貌, 看 [README-ORIGINAL-cn.md](README-ORIGINAL-cn.md).

## 1. 这门课是什么

这门课教你从零开始, 学会用一款 AI Agent Desktop App (Claude Code, Codex, 或 Antigravity) 真正干活: 怎么选, 怎么装, 界面上每个开关是什么, 以及怎么用得更快. 它不要求你有编程经验, 也不要求你有科技行业背景, 唯一的硬前置是会在 GitHub 上建 repo, clone 到本地, 以及 commit 与 push.

这是一个 readup 类型的教学仓库: 整个 repo 就是一门课, 内容拆成 [examples/](examples/) 下一个个按编号排列的 Task. 你不用把它当成一本从头读到尾的大部头, 只要照下面 "怎么读" 的路子, 一篇篇顺着读下来, 边读边照每篇的 TICKET 做, 就能学会.

---

## 2. 怎么读

1. 进 [examples/](examples/), 从 01 开始按编号往下读. 第一篇是索引, 会给你整门课的地图.
2. 每个 Task 目录里, 先读 README (这一篇教什么, 带你做什么), 再照它的 TICKET 把 "要做的事情" 逐项做完, 用 "检查清单" 自查是不是真的做到了.
3. 一篇读完再读下一篇, 直到读完最后一篇 (它会帮你梳理学到了什么, 并指出想更进一步可以往哪走).
4. 中间讲具体工具的那一块是三选一, 不是三篇都读. 选型那一篇会帮你按处境定下学哪一款, 定下之后只读属于你的那一篇, 另外两篇直接跳过.
5. 读到什么算成: 每个 Task 的 TICKET 检查清单都能逐项打勾, 且能不看教程自己把核心流程走一遍.

---

## 3. 读完你能做到什么

你能独立选定并用熟一款主流 AI Agent Desktop App, 让它替你读写文件, 召唤一个跨工具通用的 Agent Skill, 看懂上下文是怎么被悄悄吃掉的, 并养成把重要结论落进文件的习惯. 更要紧的是, 你会同时带几个 session 干活, 不再守着一个窗口发呆等结果. 换到任何一款新出的 Agent App, 你也知道该先找哪八件事.
