# Syllabus

## 01-readup

By the end you can explain the base model, ChatBot, and Agent skeleton, pick one of Claude Code, Codex, or Antigravity to fit your situation, and get genuinely comfortable with it: recognizing the switches that actually matter such as permission mode, model, and Effort, having it read and write files and screenshots, invoking an Agent Skill to get work done, understanding session and context, and using Fork to keep a clean context. You also walk away with a mindset for running several sessions at once, and the eight traits every tool in this category shares.
