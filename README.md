# Learn to Use an AI Agent Desktop App Overview

> One line: this course teaches you to pick and get comfortable with an AI Agent Desktop App from scratch, so it does real work for you. For the full picture, see [README-ORIGINAL.md](README-ORIGINAL.md).

## 1. What This Course Is

This course teaches you, from scratch, to actually get work done with an AI Agent Desktop App (Claude Code, Codex, or Antigravity): how to choose one, how to install it, what every switch in the interface does, and how to use it faster. It assumes no programming experience and no tech industry background. The one hard prerequisite is being able to create a repo on GitHub, clone it locally, and commit and push.

This is a readup style teaching repo: the whole repo is one course, and its content is split into numbered Tasks under [examples/](examples/). Don't treat it like a book you read cover to cover in one sitting. Just follow the "How to Read This" path below, read one Task after another in order, and work through each one's TICKET as you go.

---

## 2. How to Read This

1. Go into [examples/](examples/) and read in numeric order starting at 01. The first piece is the series index, and it gives you a map of the whole course.
2. In each Task folder, read the README first (what this one teaches, what it has you do), then work through its TICKET's "Things to Do" item by item, and use its "Checklist" to confirm you actually got there.
3. Finish one, move to the next, all the way through the last one (it pulls together everything you've learned and points out where to go if you want to push further).
4. The block covering specific tools is pick-one-of-three, not read-all-three. The tool-selection piece helps you settle on one based on your situation; after that, read only the piece that's yours and skip the other two.
5. What counts as done: every Task's TICKET checklist is checked off, and you can walk through the core workflow yourself without looking back at the tutorial.

---

## 3. What You Can Do When You're Done

You'll be able to pick and get comfortable with a mainstream AI Agent Desktop App on your own, have it read and write files for you, invoke a cross-tool Agent Skill, see how context gets quietly eaten up, and build the habit of putting important conclusions into files. More importantly, you'll run several sessions at once instead of sitting there watching one window and waiting. And when a new Agent App comes along, you'll know which eight things to look for first.
