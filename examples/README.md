# Learn to Use an AI Agent Desktop App, Series Index

This course teaches you, from scratch, how to get real work done with an AI Agent Desktop App. The eight mini tasks fall into four rough groups: first lay the groundwork and understand the basic shape of things; then pick a tool, decide which one to learn, and get your account set up; next, get hands-on with that tool's specific workflow; and finally, learn how to use it faster, and pull everything together into one big picture.

## 1. Lay the Groundwork

This block doesn't ask you to do anything hands-on, it just asks you to get the concepts straight in your head: why you're learning this, and what exactly you're using.

- [01-why-learn-this](01-why-learn-this/README.md): Explains why everything you'll learn and do from here on out rests on being able to use an AI Agent, and sets the boundary that this course only covers the Desktop versions.
- [02-model-chatbot-agent](02-model-chatbot-agent/README.md): Walks through the whole foundation, base model, ChatBot, Agent, in one pass, and what you're actually paying for.

---

## 2. Pick a Tool and Get Ready

With the basics in place, next comes choosing and preparing: figure out which tool fits your situation, and get a free account set up.

- [03-signup-and-pick-your-tool](03-signup-and-pick-your-tool/README.md): Based on your region and career goals, helps you settle on one of Claude Code, Codex, or Antigravity, and get the matching account set up.

---

## 3. Get Hands On with One Tool

Once you've picked your tool, you only need to read the article for that one. Each tool gets its own long-form guide, covering everything from adding a project and learning every switch in the interface, to having it read materials and write files, to using your first Agent Skill.

- [04-claude-code](04-claude-code/README.md): Getting started with Claude Code Desktop, from picking a folder to using your first Agent Skill.
- [05-codex](05-codex/README.md): Getting started with Codex Desktop, from adding a project to using your first Agent Skill.
- [06-antigravity](06-antigravity/README.md): The Antigravity article isn't published yet. This explains the current status, and how to use the Codex article as a stand-in reference if you want to start learning it right now.

---

## 4. Work Faster, See the Big Picture

Knowing how to use a tool is just the starting point. This block covers how to work faster with it, and pulls everything you've learned into one complete picture.

- [07-plan-and-delegate](07-plan-and-delegate/README.md): The mindset behind planning, breaking work into tasks, and running several sessions at once, a mindset that, at its core, is really just team management skill.
- [08-review-and-level-up](08-review-and-level-up/README.md): Lays out the seven things every Agent App of this kind has in common, points to the directions a skilled user can push further, and brings back the mindset from article 07 to close things out.

---

## 5. Summary

Put the four blocks together and you get one complete path: start with the basic shape, then make your choice, then get hands-on and fluent with one tool, and finally learn to use it faster. Once you finish this path, you haven't just learned one piece of software, you've learned the shared playbook behind this entire category of AI Agent App. Hand you any new tool in this space, and you'll already know where to look first and how to get started.
