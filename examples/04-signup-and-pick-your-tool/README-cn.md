# 先选定你的那一款, 再动手安装

> 这门课的分岔路口: 选定工具, 备好账号, 然后各走各的路.

## 1. 概览

前两篇讲完了 "为什么学" 和 "在用什么", 这一篇是动手前的最后一站, 也是整门课的分岔路口.

要办的事其实就两件: 一是把账号准备好, 二是把该学的那一款定下来. 办完这两件, 后面你只需要读属于自己的那一组文章, 其余的可以直接跳过.

---

## 2. 学习目标

很多人卡在这一步, 卡的往往不是技术, 而是选择本身: 三款工具听着都好, 到底该学哪个? 于是干脆全都看一遍, 结果哪个都没装成.

这一篇要帮你把这个纠结一次性了结掉. 记住一件事: **这三款你只需要选一款学**. 它们的用法有九成是相通的, 你把任何一款用熟, 换到另一款也就是一两天的适应期. 真正会拖垮你的, 是迟迟不做选择.

学完这个 Task, 你将能够:

1. 知道账号注册与订阅这件事该去哪儿解决, 以及为什么这门课不教它.
2. 按自己的所在地区与职业目标, 在三款工具里锁定该学的那一款, 并说得出理由.
3. 养成一个小习惯: 日后提问时, 主动报清自己用的是哪一款工具.

## 5. 装之前, 你得先有账号

这三款工具本身都是免费下载, 免费安装的. 但正如第 03 篇讲过的, 你要付钱的是大脑的算力, 所以在装之前, 你得先有一个能用的账号, 并且开好订阅.

对人在中国大陆的读者来说, 这一步的门槛不在软件, 而在一堆琐碎的现实问题: 一个能收验证码的北美邮箱, 一个稳定的美国手机号, 一种能正大光明付出去的付款方式, 以及各家订阅方案到底该选哪一档.

**这门课不教这些.** 这不是偷懒, 是分工: 这些问题细节多, 变化快, 单独讲就是一整个系列的量, 塞进这门课只会喧宾夺主.

这部分请直接看这份指南, 它把上面那些问题都覆盖了:

- [美国 AI 产品注册与订阅指南 (个人版)](https://offer-forge-public.easyscalecloud.com/projects/offer_forge_blogs/blogs/3pVkdtyRVJpyHsff/index.html)

按它把账号搞定, 然后回到这里. 从下一篇开始, 我们默认你手上已经有一个能用的账号了.

有三件事得先跟你说清楚, 免得你走岔.

**第一, 我们默认你用的是个人账号.** 这是个通用模块, 读到这里的人处境各不相同: 有人完全是自己一个人在学, 有人是跟着老师或者一个班在学. 但有一点我们统一假设, 而且九成情况都是这样: 你用的是**个人版**, 不是公司给你开的**企业版**. 如果你的情况特殊 (比如公司已经给你配好了企业版账号), 那怎么走由你自己判断, 但记得跟你的导师说一声, 别闷头照着个人版的流程硬套.

**第二, 你现在不用急着绑信用卡.** 上面那份指南教的是完整流程, 里面包含绑卡和开订阅. 但对这门课来说, 你这一步的最低要求只有一条: **账号办下来, 软件装得起来, 能成功发出去一条消息.** 免费额度确实少得可怜, 大概发个三五条就用完了. 这是正常的, 不是你哪里操作错了. 你先把整条路走通, 确认它是活的, 就算过关. 等后面你真开始高强度拿它干活, 额度不够这件事你自己会撞上, 到那时候再去升级订阅方案, 顺理成章, 一点都不晚.

**第三, 最低限度你得有一个自己的个人邮箱.** 另外给个建议: 对大部分同学来说, ChatGPT 这个账号无论如何先搞定, 它最通用, 后面很多地方都用得着. 而且如果你选的是 Codex, 它登录用的本来就是 ChatGPT 账号, 等于一步到位.

## 6. 选哪一款: 按你的处境来

现在做选择. 判断依据不是哪款技术上更牛, 而是**你的人在哪里, 你的路往哪儿走**.

**如果你长期在美国求学或就业, 选 Claude Code.** 理由很实际: 在美国企业里, Claude 目前的采用规模和使用者口碑是最强的一档. 你未来的同事, 面试官, 团队里的工具链, 大概率就是它. 学它, 学到的东西能直接换成职场上的通行证.

**如果你主要活动在中国大陆, 在 Codex 和 Antigravity 之间二选一.** 原因是 Claude 对这个地区有服务限制, 硬凑不划算, 用起来也不踏实. 剩下这两款里, 截至 2026 年年中, **Codex 比 Antigravity 更成熟, 所以更推荐**. Antigravity 起步晚, 势头很猛, 背后又是 Google, 潜力不小, 但眼下的完成度还差一截. 如果你已经深度用着 Google 的一整套东西, 或者就是想赌一把后来者, 选 Antigravity 也完全说得通.

再强调一次那个原则: **选你日常真的会用的那一款**, 然后一条路走到底. 别三个都装, 也别装完之后天天纠结是不是选错了. 选错的代价远比你想象的小, 不选的代价才大.

## 7. 选定之后, 记得报清你用的是哪一款

这一节很短, 但请放在心上.

以后你遇到问题去问人, 不管是问老师, 问同学, 还是在群里发问, 请把工具名带上. 别只说 "我用 Agent 试了一下, 不行", 而要说 "我用的是 Codex 的 Desktop 版, 我做了什么, 结果是什么".

道理很朴素: 三款工具的界面, 叫法, 脾气都不一样, 同一个问题换个工具, 答案可能完全不同. 你不说清楚, 对方就得先猜, 猜错了给你的答案自然也是错的, 一来一回浪费的还是你自己的时间.

往大了说, 这是第 02 篇那个视角的延伸: 把一件事说到别人不用猜, 本身就是做事能力的一部分. 这根弦你心里有就行, 不用刻意, 时间久了自然成习惯. 顺带一提, 你问 AI 的时候, 这条同样成立.

## 9. 练习

### 练习: 把账号办下来

**目标:** 越过这门课唯一的外部门槛. 说白了就一件事, 免费把账号注册好.

**怎么做:**

1. 确认你有一个自己的个人邮箱.
2. 打开上面那份注册与订阅指南, 按它的顺序把该办的办掉, 办到你选中那一款对应的账号能登录为止.
3. 用网页版登录一次, 随便发一条消息, 确认账号是活的.
4. 绑卡和开订阅这一步, 现在可以先跳过.

**你会观察到:**

免费额度大概三五条消息就见底了, 然后就发不动了. 别慌, 这就是免费版该有的样子, 不是你办砸了. 只要那条消息成功发出去过, 这一关就算过了.

> **关键洞见:** 先确认账号是活的, 再去装软件. 否则装到一半报错, 你会分不清到底是软件的问题还是账号的问题.

## 10. 回顾: 我们学到了什么

- 装软件之前得先有账号. 这门课不教注册, 邮箱, 美国手机号, 付款方式和各家订阅方案都在那份外部指南里.
- 我们默认你用的是个人版账号而不是企业版. 情况特殊的自己判断, 但记得跟导师说一声.
- 这一步的最低要求只是免费把账号办下来, 能发出一条消息就算过关. 不用急着绑卡, 免费额度三五条就见底是正常现象, 等真的不够用了再升级订阅.
- 选型看处境不看参数: 长期在美国求学就业选 Claude Code; 主要活动在中国大陆的, 在 Codex 与 Antigravity 之间二选一, 2026 年年中 Codex 更成熟因而更推荐.
- 三款只需选一款, 用熟一款之后换另一款只是一两天的适应期. 迟迟不选才是真的代价.
- 日后提问时报清自己用的是哪一款, 别只说 "我用了 Agent".

## 11. 导师寄语

**为什么这一篇重要:**

我见过太多人在这一步耗掉好几个星期: 收藏了一堆对比评测, 加了几个群, 每天看别人吵哪个更强, 就是没装. 半年过去了, 工具换了两代, 他还停在选择这一步.

选择本身没有那么重, 是你把它想得太重了. 这三款背后是同一个公式, 同一套骨架, 你在任何一款上练出来的手感, 换到另一款身上都算数.

**关键洞见:**

- 选定之后就别回头看了. 你要练的是用 Agent 干活的能力, 不是挑工具的眼光.
- 账号这一步看着琐碎, 但它是唯一一个卡在软件之外的门槛. 先把它清掉, 后面就是一路顺风.
