# 走通 Claude Code Desktop 的完整操作

## 1. 目标

把 Claude Code 桌面版从选定文件夹到用上 Agent Skill 的整条路径亲手走一遍. 目标不是记住每个按钮的名字, 而是让这个 App 从 "满屏不认识的东西" 变成 "我知道每个地方是干嘛的".

走完之后你手上会留下两份真实产出, 都在你自己的 repo 里: 一份 AI 根据截图写出来的说明文档, 一份 Agent Skill 生成的长文摘要.

---

## 2. 要做的事情

1. 把这个教学仓库 clone 到本地. 打开 Claude 桌面客户端, 左上角从 Home 切换到 Code.
2. 点文件夹按钮, 用 Open folder 选中 clone 下来的那个文件夹, 发出第一条消息确认链路是通的.
3. 把 Local, main 与 worktree, 加文件夹按钮, 权限模式, 加号菜单, Model, Effort 这七个地方挨个点开看一遍, 把权限模式设成 Auto.
4. 把 Claude Code 界面本身截个图粘进输入框, 让它根据这张图写一份文档到 tmp 目录下的某个 md 文件里. 写完点聊天记录里的文件链接看渲染结果, 再用竖三点菜单打开 Files 在文件树里找到它.
5. 读它写的这份文档, 挑一处跟你实际看到的界面对不上的地方, 再截一张图追问, 并让它联网搜一下, 看它怎么修正自己.
6. 在文件树里找到 resources 目录下的 claude-agent-skills.md, 右键 Attach as context. 输入斜杠加 summari, 按 Tab 补全后发送, 观察输出的结构.
7. 输入斜杠加 context, 把那张拆解表从头看到尾, 特别注意 Messages 那一行占了多少, 总共用掉了多少.
8. 挑中间任意一条消息, 点 Fork from here, 确认新会话只继承到岔口之前的历史.

**预计用时:** 90 到 120 分钟

---

## 3. 检查清单

- [ ] **工作文件夹已选定**: 你从 Home 切到了 Code, 选中了本地的仓库文件夹, 并且第一条消息成功收到了回复.
- [ ] **认识每个 widget**: Local, main 与 worktree, 加文件夹, 权限模式, 加号菜单, Model, Effort 你都点开看过, 并且能说出各自是干什么的.
- [ ] **权限模式的取舍**: 你能说清 Auto 为什么是日常首选, Plan 模式在什么场景下值得先用一次, 以及 Bypass permissions 为什么只适合能为自己损失兜底的人.
- [ ] **Effort 的判断**: 你能举出至少两种任务, 分别说明该靠 Faster 端还是 Smarter 端, 并说清为什么不是越高越好.
- [ ] **交材料与写文件**: 你用截图交过材料, 也让 AI 把产出写到了你指定的路径, 并且知道 tmp 目录是被 gitignore 的临时区.
- [ ] **截图问 AI 这个方法**: 你把界面截图丢给 AI 问过一次, 也针对一处对不上的地方追问过一次并让它联网搜, 并且认可这是搞懂任何陌生软件最直白的一条路.
- [ ] **审阅改动**: 你点过聊天记录里的文件链接看渲染结果, 也用 Files 面板浏览过文件树.
- [ ] **用过 Agent Skill**: 你成功召唤了 summarize skill 并拿到了摘要, 并且能指出这个 skill 的真身就是 .claude 目录下 skills 里 summarize 的那个 SKILL.md 文件.
- [ ] **看穿上下文**: 你跑过 context 命令, 能说出 Messages 那一行占了多少而总共用掉了多少, 也能说出至少三样占着上下文但在聊天记录里看不见的东西 (系统提示词, 工具说明, skill 清单, 读过的文件全文, 中间步骤).
- [ ] **fork 成功**: 你 fork 出了一个新会话, 并确认它只继承了到岔口之前的历史.
