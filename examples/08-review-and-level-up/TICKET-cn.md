# 给你的 Agent App 打一遍共性清单

## 1. 目标

把第 08 篇讲的七件共性和拔高方向, 落到你自己那款工具上验证一遍. 这一步做完, 你不仅用熟了一款 Agent App, 还知道换任何一款新的都该先找什么.

---

## 2. 要做的事情

1. 通读本目录下的 README, 重点是第 5 到第 13 节的共性清单和拔高方向.
2. 打开你在第 04 或第 05 篇用熟的那款工具, 对照七件共性逐条在界面上找到它.
3. 挑一件真实的小事, 完整走一遍: 绑好文件夹, 派活让它读写文件, 中途查一眼上下文占用, 调一次模型或 Effort.
4. 从当前对话 Fork 出一条分支, 试一次不一样的做法, 确认原来那条线没受影响.
5. 写一句话总结: 这七件事里哪一件你之前没留意过, 现在认清了.

**预计用时:** 30 到 45 分钟

---

## 3. 检查清单

- [ ] **七件共性都点过**: 你在自己那款工具的界面上, 逐一确认过绑定文件夹, 文件浏览器, 读写文件与图片, session 与上下文, 模型与 Effort, Agent Skill, Fork 这七件事都在哪儿, 怎么用.
- [ ] **真实任务走完整一遍**: 你用一件真实的小事, 完整走过绑地盘到出结果的全过程, 而不是零散地点了几个按钮.
- [ ] **Fork 用过一次**: 你实际 Fork 过一次对话, 并确认原来的对话没有受影响.
- [ ] **拔高方向说得清**: 你能说出专业开发者还能往哪几个方向把这套工具用得更狠 (开发工具, 终端, 自动化操作浏览器等).
- [ ] **一句话总结已写下**: 你写了一句话记录这次打勾过程里最意外的发现.
