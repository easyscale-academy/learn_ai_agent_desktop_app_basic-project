# Run the Shared Traits Checklist Against Your Agent App

## 1. Goal

Verify the seven shared traits and the level up directions from Task 08's README against the tool you're actually using. Once you've done this, you'll not only be comfortable with one Agent App, you'll know exactly what to look for first the next time you pick up a new one.

---

## 2. What to Do

1. Read through the README in this directory, focusing on the shared traits checklist and level up directions in sections 5 through 13.
2. Open the tool you got comfortable with in Task 04 or Task 05, and locate each of the seven shared traits in its interface, one by one.
3. Pick one small, real task and walk through the whole flow: bind a folder, hand off work that reads and writes a file, check context usage partway through, and adjust the model or Effort once.
4. Fork off from the current conversation, try a different approach, and confirm the original conversation is untouched.
5. Write one sentence summarizing which of these seven things you hadn't noticed before, and now you have.

**Estimated time:** 30 to 45 minutes

---

## 3. Checklist

- [ ] **All seven shared traits checked off**: In your own tool's interface, you've confirmed, one by one, where and how to use folder binding, the file explorer, reading and writing files and images, session and context, model and Effort, Agent Skill, and Fork.
- [ ] **A real task run start to finish**: You used one small, real task to walk the complete flow from binding your territory to getting a result, not just clicking around at a few buttons here and there.
- [ ] **Fork used once**: You actually forked a conversation once, and confirmed the original conversation was unaffected.
- [ ] **Level up directions clearly stated**: You can name the directions a professional developer can push this toolset further in (dev tools, the terminal, browser automation, and so on).
- [ ] **One-sentence summary written**: You wrote one sentence recording the most surprising thing you found while working through this checklist.
