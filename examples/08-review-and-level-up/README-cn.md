# 回顾与拔高, 你已经基本会用 AI Agent 了

> 这是这门课最后一篇. 不再教新东西, 只做一件事: 把前面几篇拆开揉碎, 拼成一张你带得走的全景图.

## 1. 写在最后一篇的开头

走到这里, 你至少用熟了 [Claude Code](../04-claude-code/README-cn.md) 或 [Codex](../05-codex/README-cn.md) 其中一款 (Antigravity 那篇还没开放, 见 [第 06 篇](../06-antigravity/README-cn.md) 的说明), 也在 [第 07 篇](../07-plan-and-delegate/README-cn.md) 里练过怎么用它更快. 这一篇不再教新按钮, 而是做两件事: 把这些工具身上共通的东西挑出来, 让你以后换任何一款都不用从头学; 再把第 07 篇的心法接回来, 收个尾.

---

## 2. 先把地盘划出来, 绑定文件夹和 GitHub Repo

不管是 Claude Code, Codex 还是 Antigravity, 开工第一件事永远是一样的: 给它一块地盘. 这块地盘就是一个本地文件夹, 通常也对应一个 GitHub Repo. 没有这块地盘, Agent 无从下手, 它读不到你的东西, 也没地方写.

[第 01 篇](../01-why-learn-this/README-cn.md) 说过 "一件事就是一个文件夹, 这个文件夹就是一个 repo", 你在第 04, 05 篇里亲手选过这块地盘. 这不是某一款工具的特性, 是所有这类 Agent App 的共同起点.

---

## 3. 用文件浏览器看清地盘里有什么

绑好文件夹之后, 三款工具都配了一个**文件浏览器**, 让你随时能看清这块地盘里现在都有什么, Agent 刚刚改了哪些文件. 它不是装饰, 是你信任 Agent 干活的重要依据: 它说它做完了, 你打开文件浏览器扫一眼, 就知道它是不是真的做了, 做得对不对.

---

## 4. 读写文件, 也读写图片

有了地盘, 有了浏览器, 剩下的就是干活本身. 三款工具都能**读写文件**, 也都能**读写图片**: 你可以把一张截图丢给它, 让它看懂界面上有什么; 也可以让它读一份文档, 帮你改, 帮你写, 帮你整理成新的文件. 这是它们作为 Agent (而不只是 ChatBot) 最基本的能力, [第 02 篇](../02-model-chatbot-agent/README-cn.md) 讲过的那个公式, 基座模型加 Harness, 落到实处就是这个.

---

## 5. Session, chat, 上下文, 同一套记忆模型

三款工具都用同一套方式组织你和它的交互: 一个 **session** 就是一次围绕某个目标展开的对话, session 内部是一轮一轮的 **chat**, 而这些对话攒起来, 加上它读过的文件, 就构成了这次它脑子里装着的 **上下文**.

这套模型不是巧合, 是所有 Agent App 都得解决同一个问题: 怎么让 AI 记得住这次任务从哪儿开始, 走到哪儿了. [第 07 篇](../07-plan-and-delegate/README-cn.md) 教你写计划文档, 本质上就是在给这套记忆模型上一道保险: 上下文会丢, 文件不会.

---

## 6. 调整模型和 Effort, 换挡开车

三款工具都能让你选**模型**, 也都能调 **Effort** (思考力度). 这就像开车换挡: 简单直给的活, 用便宜快的档位就够了; 复杂需要深想的活, 换到更聪明更肯下功夫的档位, 虽然更贵更慢, 但值得. 第 02 篇讲过, 你付的钱买的是算力, 这里的模型和 Effort 选择, 就是你在具体花钱花在哪儿这件事上, 手上的那个调节旋钮.

---

## 7. Agent Skill, 一个全世界统一的标准

三款工具都支持 **Agent Skill**, 而且这不是各家各自发明的功能, 是**一个全世界统一的标准**. 你在 Claude Code 里学会怎么用一个 Skill, 换到 Codex 或 Antigravity, 用法基本不变, 顶多是界面位置不同. 你在第 04, 05 篇亲手用过一个极简的 summarize skill, 那就是这套标准最基础的用法: 把一套你反复要用的干活方式, 写成 Agent 能照着执行的说明书.

---

## 8. Fork, 从一个岔路口重新出发

三款工具都有 **Fork** 功能: 从对话中的某一点岔开, 开出一条新的分支, 而不影响原来那条线. 这在你想 "试试另一种做法, 但又不想丢掉现在这条路已经走到的进度" 时特别好用, 跟 Git 里的分支是同一个思路, 只不过分的是对话, 不是代码.

---

## 9. 专业选手还能往上叠几层

以上七件事, 是这类 Agent App 的地基, 普通用户配合文件浏览器就基本够用了. 但如果你是专业开发者, 这块地基上还能往上叠好几层: 配合专业的开发工具和编程语言, 配合终端, 让 AI 自动化操作浏览器去帮你测试或抓取信息, 更激进一点, 甚至能通过某些方式让它直接操作你的鼠标键盘, 操作整个操作系统.

这些内容这门课不展开讲, 算是专业用户的自留地. 但你需要记住一句话: **基本上你这个人类能干的任何事情, AI 都能干, 而且大概率比人类干得更好.** 你现在只是刚刚入门, 但你已经推开了这扇门.

---

## 10. 把第 07 篇的心法接回来

上面这七件事和这一层拔高, 只是给你一张工具地图. 真正决定你效率的, 是 [第 07 篇](../07-plan-and-delegate/README-cn.md) 讲的那套心法: 遇到 session 会丢的问题, 靠写计划文档解决; 遇到几件事都要做的问题, 先分清哪些是探索型哪些是执行审阅型; 探索的顺序来, 想到七成成熟就停; 执行的可以同时开几个 session, 你来回切换, 当那个审阅进度的老板.

工具会换, 版本会升级, 界面会改样子. 但这张全景图, 地基七件事加上带它干活的心法, 换到任何一款新出的 Agent App 上, 基本都还能用. 这才是这门课真正想留给你的东西.

## 12. 导师寄语

**为什么这一篇重要:**

前面每一篇都在教你一个具体的东西, 一款工具, 一个功能, 一个心法. 这一篇不教新东西, 它教你怎么把学过的东西拼起来看. 拼起来看, 你才会发现自己学到的比想象中更多, 也更通用.

**关键洞见:**

- 具体工具会一茬一茬地换, 但这七件事和第 07 篇那套心法, 是压在所有工具下面的地基, 不会轻易过时.
- 你不需要把所有拔高方向都学会才算毕业. 知道它们存在, 知道自己现在站在哪一层, 就已经够用了.

**写在最后:**

这门课到这里就结束了. 接下来该怎么走由你自己定: 继续把手上那款工具用深, 去摸一摸没学过的另一款, 或者往专业拔高的方向探一探. 不管走哪条路, 你带走的这张全景图都用得上.
