# Get Clear on This Course, Its Purpose and Approach

## 1. Goal

Before installing any software, get clear on where this course sits and what its boundaries are, and confirm you've already cleared the one hard prerequisite (basic GitHub operations). This step doesn't produce any code, it produces a way of approaching work that you'll keep using going forward.

---

## 2. What to Do

1. Read through the README in this directory, paying special attention to the two sections on the mini project lens and Agent Skill.
2. Write down three things you genuinely want to learn or build lately, and add one sentence to each: what it's meant to solve, and what you'll have in hand once it's done.
3. Check your GitHub basics: can you create a repo on GitHub, clone it locally, and commit and push back? If you're not confident, go pick it up first before moving on, every piece after this one assumes you already know it.
4. Close the document and try answering three questions in your own words: which three tools does this course teach? Why only the Desktop versions? Why does it skip Cursor style tools?

**Estimated time:** 20 to 30 minutes
