## 5. 基座模型: 整套 AI 的大脑

一切的核心, 是**基座模型** (英文 foundation model, 中文也常叫大模型).

你可以把它理解成整套 AI 的大脑. 你问它问题, 它思考, 它回答, 它写东西, 它替你干活, 靠的都是这个大脑. 上一篇说过, 全世界把基座模型做进第一梯队的就三家: OpenAI (模型是 GPT 系列), Anthropic (模型叫 Claude), Google (模型叫 Gemini).

现在记住一件事, 后面很多困惑都能靠它解开: **真正值钱, 真正要花钱的, 是这个大脑.** 你后面会看到的各种软件, 各种界面, 各种花里胡哨的产品, 都只是这个大脑的不同用法和不同外壳. 大脑就那么几个, 壳可以有无数层.

---

## 6. ChatBot: 你最先摸到的那层壳

普通人接触 AI, 几乎都是从聊天开始的: 打开一个网页, 在输入框里打字, 它回你一段话. 这个东西叫 **ChatBot** (聊天机器人).

ChatBot 是套在大脑外面的第一层壳, 也是最简单的一层. 你在 claude.ai, chatgpt.com, gemini.google.com 里聊天, 本质是同一件事: 你打字, 你的话被送进那个大脑, 大脑想好了, 再把答案显示回来给你.

它好上手, 门槛低, 随便问问, 查查资料都很合适. 但它有个天花板: 它基本只会 "你问一句, 它答一句". 你要它真正替你把一件复杂的事从头做到尾, 光靠聊天是不够的. 这就引出了更重要的下一层.

---

## 7. Agent: 会干活的那层壳

**Agent** (智能体), 是套在大脑外面更厉害的一层壳.

差别是这样的: ChatBot 是你问一句它答一句; Agent 则是你交代一个目标, 它自己拆解步骤, 自己动手, 一步一步把事情做完. 它能读文件, 能改文件, 能运行程序, 能自己检查结果对不对, 发现做错了还会退回去重来一遍. 它就是大家常说的那种 "干活能力和解决问题的能力比大部分白领还强" 的东西. 而且它可以被自定义, 你能按自己的需要, 教它该怎么干活 (还记得第 01 篇里的 Agent Skill 吗? 那就是自定义它的方式).

那 Agent 是怎么变得这么能干的? 它的本质, 是在基座模型外面套了一整套精心设计的框架: 让大脑能调用工具, 能读写文件, 能记住上下文, 能循环着自我修正. 这套框架在业内有个专门的名字, 叫做 **Harness**.

所以记住这个公式:

**Agent = 基座模型 + Harness**

同一个大脑, 套上一套好的 Harness, 就从一个会聊天的变成一个会干活的. 这个会干活的 Agent, 才是我们这门课最终要让你用上的东西.

这个公式也顺手解释了上一篇留下的那个疑问: 为什么 Cursor 那一类产品护城河薄. 因为它们做的是 Harness 那一半, 大脑那一半是租来的. 而这两半里, 难的, 贵的, 别人短期抄不走的, 恰恰是大脑那一半.

---

## 8. 为什么这些 Agent 都是靠写代码出的名

你可能已经注意到一件事: 今天最出名的这些 Agent, 名字里, 宣传里, 好像全都在讲写代码. 很多人于是以为, 这东西是给程序员用的, 跟我没关系.

这是个误会. **Agent 本质上能做任何事**, 写代码只是它最先被拿来证明自己的那个赛道. 为什么偏偏先挑了写代码? 因为**编程是最容易验证对错的领域**.

你想想, 如果让 AI 帮你治好一个病, 或者帮你把公司经营好, 到底怎么才算做好了? 根本没有一个当场就能验证的标准, 见效还慢. 写代码不一样: 代码能不能跑通, 测试能不能通过, 功能对不对, 当场就见分晓, 对就是对, 错就是错.

对一家想让自己的 Agent 快速成熟起来的公司来说, 这个选择就很显然了: 先扎进一个能被快速, 客观验证的赛道, 用它把能力打磨扎实, 顺便把名气打出来. 所以这些 Agent 都从写代码起步.

但你千万别被这层出身误导: 它骨子里是一个通用的干活工具, 不是一个只会写代码的玩具. 你拿它整理资料, 写文档, 做研究, 一样好使.

## 9. 一条时间线: 从大模型到超级 App

把上面这些放进时间里看, 这几年发生的事其实脉络很清楚.

**第一阶段, 只有大脑.** 2022 年底 ChatGPT 引爆, 大众第一次亲手摸到大模型. 那一两年比的是模型本身够不够聪明, 而你能做的基本只有聊天.

**第二阶段, 粗糙的 Agent.** 2023 年前后, 有人开始试着让模型自己调用工具, 自己循环着干活, 那个年代最出名的尝试叫 AutoGPT. 想法是对的, 但东西很粗糙: 经常跑偏, 跑着跑着就乱了, 更像一个让人惊呼一声的 demo, 而不是真能交付的生产力.

**第三阶段, 大放异彩.** 到 2025 年, 两件事同时成熟了: 模型本身强到能稳定地做多步推理和工具调用, 外面那层 Harness 也被打磨得足够扎实. Agent 第一次真正好用起来, 突破口正是上一节说的写代码.

**第四阶段, 全部跟进.** 一家做出来之后, 另外两家迅速跟上. 到 2025 年底, 三家都摆出了自己的桌面 Agent: Claude Code, Codex, Antigravity. 格局就此定下来.

**第五阶段, 长成超级 App.** 到 2026 年的今天, 这些工具早就不只是 "写代码的" 了. 它们能读你的文件, 能上网查资料, 能操作你的电脑, 能接上你的聊天软件, 能按你教的方式干活. 它们正在变成一个入口: 你什么事都先找它.

看懂这条线你会发现, 每一步的进展都发生在同一个公式的两半上. 要么大脑变强, 要么 Harness 变好. 从来没跳出过这个框架.

## 10. CLI 和 Desktop: 同一个 Agent 的两种长相

同一个 Agent, 通常有两种长相, 也就是两种你跟它打交道的方式.

一种叫 **CLI** (命令行界面, Command Line Interface). 它长得就是一个黑乎乎的纯文字窗口, 你敲文字命令, 它回文字. 之所以长这样, 是因为 Agent 最早是做给专业开发者用的, 而开发者本来就天天泡在这种窗口里. CLI 很强大也很灵活, 但对大部分人来说学习成本偏高, 第一眼就容易劝退.

另一种叫 **Desktop** (桌面版). 它就是装在你电脑上的一个普通软件, 有窗口, 有按钮, 有聊天框, 跟你平时用的其他 App 没什么两样, 点点鼠标就能上手.

这两种形态不是谁取代谁, 而是各有各的场合: CLI 在某些活儿上更强更灵活, Desktop 在另一些活儿上更顺手更直观. 顺便说一句, 用 Desktop 一点都不 "低级": 很多专业开发者也有相当一部分时间是在 Desktop 里干活的. 它是正经的主力工具之一.

这门课主打对新手最友好的 **Desktop 版本**.

## 11. 你付的钱, 买的是算力不是软件

理清了上面这些, 有一个很多人搞不清的问题现在一句话就能说明白: **你花钱买的是那个大脑的算力, 不是外面那层软件.**

想想看, Claude Code, Codex, Antigravity 这些 Agent 软件, 是装在你自己电脑上, 跑在你自己电脑上的. 它们运行时烧的是你自家的硬件, 没花人家数据中心一分钱, 所以软件本身往往免费下载, 免费安装.

但大脑不一样. 它太大了, 装不进你的电脑, 只能待在 OpenAI, Anthropic, Google 的数据中心里. 你每让它思考一次, 干一次活, 那边都要实打实地烧电, 占用极其昂贵的硬件. 这是真金白银的成本. 所以要收钱的从来是大脑, 是它的算力.

这也解释了另一件事: 为什么后面几篇要专门花篇幅讲订阅方案怎么选. 你选的不是软件版本, 你选的是能用多少算力.

## 12. 再往前一步: OpenClaw 这类个人 AI 操作系统

最后聊一个你大概率已经在中文互联网上刷到过的东西: **小龙虾**.

它的正式名字叫 **OpenClaw**, 作者是 Peter Steinberger, 开源, 装在你自己的机器上. 它改过好几次名字: 最早叫 Clawdbot, 后来因为读音和 Claude 太像被要求改名, 短暂地叫过 Moltbot, 最后在 2026 年 1 月底定名 OpenClaw. 所以你在不同时期的文章里会看到不同的叫法, 说的都是同一个东西.

它和 Claude Code 这类工具的差别在哪? Claude Code 是你要用的时候打开它; 而 OpenClaw 是一个常驻的 Gateway, 把你的 WhatsApp, Telegram, 微信, 飞书等一大堆聊天渠道全接进来, 你在哪儿发条消息, 它就在你的机器上把活给干了. 这个形态更像一个操作系统, 而不是一个应用. 国内也有对标产品, 比如网易有道的 LobsterAI.

同一类里还有另一个代表, 叫 **Hermes Agent**, 来自 Nous Research. 它走的是另一条路: 不拼接入渠道多, 而是拼自我进化, 每干完一件事就自己沉淀出新的 Skill, 下次做得更好.

这类东西该怎么定位? 你现在有骨架了, 一句话就能归位: 它们本质上是**自定义版本的, 更复杂的 Claude Code / Codex / Antigravity**. 底下还是同一个公式, 基座模型加 Harness, 只不过 Harness 那一层被做得更大, 更像一个平台. 这门课不展开讲它们.

那到底需不需要追? 给你一个判断. 如果你是企业里的员工, Claude Code, Codex, Antigravity 这三款已经能覆盖你 99% 的工作, 完全不用操心别的. 如果你是创业者, 这类 AI 操作系统大概能多做 5% 到 10% 那三款做不到的事. 但反过来说也成立: 把这三款用熟, 哪怕对创业者, 90% 以上的事情也已经够够的了.

所以结论很朴素: 先把地基打好. 地基打好了, 上面加什么都快.

## 13. 练习

### 练习 1: 用大白话把骨架讲一遍

**目标:** 检验你是真懂了, 还是只是读过了.

**怎么做:**

1. 找一个完全不懂这些的人 (家人, 朋友都行), 或者干脆对着录音自言自语.
2. 用不超过三分钟, 讲清四件事: 大脑是什么, ChatBot 是什么, Agent 凭什么比 ChatBot 强, 你花的钱花在哪儿了.
3. 全程不许用 Harness, foundation model 这种词, 只准用大白话和比喻.

**你会观察到:**

讲不下去的地方, 就是你其实没懂的地方. 回去把那一节重读一遍.

> **关键洞见:** 能用大白话讲明白, 才叫懂. 能复述术语, 只叫见过.

### 练习 2: 给几个东西归位

**目标:** 把骨架当成一把尺子用起来.

**怎么做:**

1. 列出你听说过的四五个 AI 产品, 比如 claude.ai 网页版, Claude Code, Cursor, OpenClaw, 以及任何你最近刷到的新玩意.
2. 对每一个回答三个问题: 它是 ChatBot 还是 Agent? 它背后用的是谁的大脑, 是自家的还是租来的? 它是 CLI 还是 Desktop 形态?
3. 遇到答不上来的, 去它官网上找一找, 通常几分钟就能查清.

**你会观察到:**

大部分产品都能被这三个问题干净地归位. 归不了位的, 往往是营销词堆得太厚, 而不是技术上真有什么新东西.

> **关键洞见:** 有了骨架, 你就不用再追新闻了. 新产品出来, 拿这把尺子一量, 三句话就知道它是什么货色.

## 14. 回顾: 我们学到了什么

- 基座模型是大脑, 全世界第一梯队就 OpenAI, Anthropic, Google 三家. 值钱的是大脑.
- ChatBot 是最简单的一层壳, 你问一句它答一句.
- Agent 是会干活的那层壳, 公式是基座模型加 Harness. 它自己拆步骤, 自己动手, 自己纠错.
- 这些 Agent 都从写代码起家, 只因为编程是最容易当场验证对错的赛道, 不代表它只会写代码.
- 时间线是: 只有大脑, 粗糙的 Agent, 大放异彩, 三家跟进, 长成超级 App. 每一步都发生在公式的两半上.
- 同一个 Agent 有 CLI 和 Desktop 两种长相, 各有各的场合, 这门课教 Desktop.
- 你付的钱买的是大脑的算力, 软件本身通常免费.
- OpenClaw, Hermes Agent 这类个人 AI 操作系统, 本质是更复杂的自定义版 Agent. 先把三款主流工具用熟, 90% 以上的事都够了.

## 15. 导师寄语

**为什么这一篇重要:**

这一篇是整个系列里唯一一篇你读完之后, 手上什么都没多的文章. 但它是性价比最高的二十分钟.

因为 AI 这个领域最消耗人的, 不是学不会, 是天天被新名词轰炸带来的那种焦虑感: 又出了个新东西, 我是不是又落后了? 骨架就是治这个病的药. 你有了它, 再看新产品, 看到的不再是一堆陌生名词, 而是几块熟悉的积木换了个搭法.

**关键洞见:**

- 壳会一茬一茬地换, 大脑只有那么几个. 判断一个产品值不值得你投入时间, 先看它有没有自己的大脑.
- 每一次所谓的重大突破, 拆开看都是这个公式的某一半变强了. 知道这一点, 你就不容易被营销话术唬住.
