# 讲清基座模型, ChatBot 与 Agent 的关系

## 1. 目标

把这几个绕来绕去的名词一次性理顺, 在脑子里立起一张骨架图. 立住之后, 后面每一篇的选型, 订阅, 安装, 你都能明白自己在干什么, 也不会再被层出不穷的新产品名词晃花眼.

---

## 2. 要做的事情

1. 通读本目录下的 README, 重点是 Agent 等于基座模型加 Harness 这个公式, 以及那条从大模型到超级 App 的时间线.
2. 找一个完全不懂这些的人, 或者对着录音, 用不超过三分钟, 全程大白话, 讲清四件事: 大脑是什么, ChatBot 是什么, Agent 凭什么比 ChatBot 强, 你花的钱花在哪儿了. 讲不下去的地方回去重读.
3. 列出四五个你听说过的 AI 产品, 逐个回答三个问题: 它是 ChatBot 还是 Agent, 它背后的大脑是自家的还是租来的, 它是 CLI 还是 Desktop 形态. 查不到的就去官网找.
4. 用一句话写下你对 OpenClaw 这类个人 AI 操作系统的定位判断, 以及你现阶段要不要追它.

**预计用时:** 30 到 45 分钟

---

## 3. 检查清单

- [ ] **三层关系**: 你能说清基座模型, ChatBot, Agent 各是什么, 以及它们是怎么一层套一层的.
- [ ] **核心公式**: 你能解释 Agent 等于基座模型加 Harness, 并用它说清为什么没有自家模型的产品护城河薄.
- [ ] **出身之谜**: 你能讲清这些 Agent 都从写代码起家的真正原因, 是编程最容易当场验证对错, 而不是它只会写代码.
- [ ] **两种形态**: 你能说出 CLI 与 Desktop 的区别, 以及这门课为什么选 Desktop.
- [ ] **付费对象**: 你能一句话讲明白, 收钱的是大脑的算力, 软件本身通常免费.
- [ ] **归位能力**: 你完成了产品归位练习, 并能用这套骨架给 OpenClaw 这类新东西定位.
