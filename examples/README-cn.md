# 学会用 AI Agent Desktop App 系列索引

这门课教你从零开始, 学会用一款 AI Agent Desktop App 干活. 八篇 mini task 大致分四块: 先打地基, 弄懂骨架和为什么要学; 再选型, 定下要学哪一款工具, 把账号办好; 然后上手一款工具的具体操作; 最后讲怎么用它用得更快, 并把全部内容收成一张全景图.

## 1. 打地基, 弄懂骨架

这一块不需要你动手, 只需要把脑子里的概念理顺: 为什么要学, 以及你到底在用什么.

- [01-why-learn-this](01-why-learn-this/README-cn.md): 说清为什么后面所有的学习与做事都建立在会用 AI Agent 之上, 也定下这门课只教 Desktop 版本的边界.
- [02-model-chatbot-agent](02-model-chatbot-agent/README-cn.md): 一次性讲透基座模型, ChatBot, Agent 这套骨架, 以及你付的钱到底买的是什么.

---

## 2. 选型, 把该准备的准备好

有了骨架, 接下来是选择和准备: 按自己的处境定下要学哪一款, 把账号免费办下来.

- [03-signup-and-pick-your-tool](03-signup-and-pick-your-tool/README-cn.md): 按所在地区与职业目标, 在 Claude Code, Codex, Antigravity 三款里锁定要学的那一款, 并把对应账号办好.

---

## 3. 上手一款工具

选定之后, 只读属于你的那一篇. 每款工具一篇长文, 从添加项目, 认识界面上每一个开关, 到让它读材料写文件, 再到用上第一个 Agent Skill, 全部讲透.

- [04-claude-code](04-claude-code/README-cn.md): Claude Code Desktop 上手, 从选定文件夹到用上第一个 Agent Skill.
- [05-codex](05-codex/README-cn.md): Codex Desktop 上手, 从添加项目到用上第一个 Agent Skill.
- [06-antigravity](06-antigravity/README-cn.md): Antigravity 这一篇还没开放, 说明现状, 以及现在就想学的话该怎么先拿 Codex 篇当参照.

---

## 4. 用得更快, 拼成全景图

会用只是起点, 这一块讲怎么用得快, 再把前面学到的全部内容收成一张全景图.

- [07-plan-and-delegate](07-plan-and-delegate/README-cn.md): 做计划, 分任务, 同时带几个 session 干活的心法, 这套心法本质上也是团队管理能力.
- [08-review-and-level-up](08-review-and-level-up/README-cn.md): 梳理这类 Agent App 共有的七件事, 指出专业选手还能往哪几个方向拔高, 并把第 07 篇的心法接回来收尾.

---

## 5. 小结

四块拼起来, 走的是一条完整的路: 先有骨架, 再做选择, 然后亲手用熟一款工具, 最后学会怎么用它用得快. 读完这条线, 你不只是学会了一款软件, 你学会的是这一整类 AI Agent App 的共同打法, 换任何一款新工具, 你都知道该先看什么, 怎么上手.
