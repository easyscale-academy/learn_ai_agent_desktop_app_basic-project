# Walk through the complete Codex Desktop workflow

## 1. Goal

Walk through the entire path in Codex Desktop yourself, from adding a project to using an Agent Skill. The goal isn't to memorize every button's name; it's to turn this app from "a screen full of things I don't recognize" into "I know what every part of this does."

By the end you'll have two real artifacts sitting in your own repo: a how-to document the AI wrote from a screenshot, and a summary of a long article generated by an Agent Skill.

---

## 2. What to do

1. Clone this teaching repo locally. Open the ChatGPT desktop client and switch from ChatGPT to Codex in the top left.
2. Use New project to add the cloned folder as a project, and send a first message to confirm the pipeline works.
3. Click through all six widgets, Local, main, approval mode, Model, Effort, and Speed, and set approval mode to Approve for me.
4. Take a screenshot of the Codex interface itself, paste it into the input box, and have it write a document based on that image into a markdown file under the tmp directory. Once it's done, click Review to see the diff, then use the plus icon on the right to open Files and check the rendered output in the file browser.
5. Read the document it wrote, pick a spot that doesn't match what you actually see in the interface, take another screenshot, follow up, and have it search the web too, and see how it corrects itself.
6. Find openai-agent-skills.md under the resources directory in the file tree and right-click Add to chat. Type slash plus summari, press Tab to autocomplete, follow it with this file, send, and observe the structure of the output.
7. Type slash plus status and check your remaining context and remaining usage, and make sure you understand why that number is bigger than your intuition suggests.
8. Pick any message in the middle of the conversation, click fork, choose Use this workspace, and confirm the new conversation only inherits history up through that message.

**Estimated time:** 60 to 90 minutes
