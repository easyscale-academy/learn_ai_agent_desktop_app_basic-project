## 2. 现在就想学 Antigravity, 怎么办

先去读 [第 05 篇](../05-codex/README-cn.md) Codex. 三款工具背后是同一套骨架 (第 02 篇讲过的 ChatBot 与 Agent 两层壳, 权限模式, 模型选择, Agent Skill 这些概念都通用), Antigravity 的基本操作流程和 Codex 高度相似.

把 Codex 那篇当参照, 打开 Antigravity, 对照着一步步摸索; 遇到界面对不上的地方, 把界面截图丢给 AI, 让它照着截图告诉你这是什么, 该点哪里. 这条路稍微费点劲, 但走得通.
