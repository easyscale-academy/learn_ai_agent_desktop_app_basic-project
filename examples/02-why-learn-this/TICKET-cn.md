# 读懂这门课的定位与做事视角

## 1. 目标

在动手装任何软件之前, 先把这门课的位置和边界想清楚, 同时确认自己已经越过了唯一的硬前置 (GitHub 的基本操作). 这一步不产出代码, 产出的是一个能一直用下去的做事视角.

---

## 2. 要做的事情

1. 通读本目录下的 README, 重点是讲 mini project 视角和 Agent Skill 的那两节.
2. 写下你最近真的想学或者想做的三件事, 给每件事补一句话: 它要解决什么, 做完手上会多出一个什么东西.
3. 自查 GitHub 底子: 在 GitHub 上创建 repo, clone 到本地, commit 并 push 回去, 这三件事你会不会? 心里没底就先去补一下再往后走, 后面每一篇都默认你已经会了.
4. 合上文档, 试着用自己的话回答三个问题: 这门课教哪三款工具? 为什么只教 Desktop? 为什么不教 Cursor 那一类?

**预计用时:** 15 到 30 分钟

---

## 3. 检查清单

- [ ] **读完总纲**: 你能说清为什么这门课要排在整条学习路线的最前面.
- [ ] **mini project 视角**: 你写出了三件事, 每件事都有一句话的边界描述, 并且都能塞进一个文件夹.
- [ ] **Agent Skill 的位置**: 你能讲清 Skill 是什么, 以及它的边界为什么正好是一个 mini project 的边界.
- [ ] **GitHub 前置达标**: 创建 repo, clone 到本地, commit 与 push 这三件事你确认自己会做, 心里没底的部分已经补上.
- [ ] **课程边界**: 你能说出这门课教的三款工具, 说清只教 Desktop 的原因, 也能讲清不教 Cursor 那一类的理由是它们背后没有自己的模型.
