# 学会用 AI Agent Desktop App 系列索引

这门课教你从零开始, 学会用一款 AI Agent Desktop App 干活. 除了你正在读的这一篇, 后面还有八个 mini task, 大致分四块: 先打地基, 弄懂骨架和为什么要学; 再选型, 定下要学哪一款工具, 把账号办好; 然后上手一款工具的具体操作; 最后讲怎么用它用得更快. 走完这四块, 还有一篇收尾, 把全部内容收成一张全景图.

这一篇本身不教任何东西, 它只是一张地图: 你先花几分钟看清路怎么走, 再回头一篇篇读下去.

## 1. 打地基, 弄懂骨架

这一块不需要你动手, 只需要把脑子里的概念理顺: 为什么要学, 以及你到底在用什么.

- [02-why-learn-this](../02-why-learn-this/README-cn.md): 说清为什么后面所有的学习与做事都建立在会用 AI Agent 之上, 也定下这门课只教 Desktop 版本的边界.
- [03-model-chatbot-agent](../03-model-chatbot-agent/README-cn.md): 一次性讲透基座模型, ChatBot, Agent 这套骨架, 以及你付的钱到底买的是什么.

---

## 2. 选型, 把该准备的准备好

有了骨架, 接下来是选择和准备: 按自己的处境定下要学哪一款, 把账号免费办下来.

- [04-signup-and-pick-your-tool](../04-signup-and-pick-your-tool/README-cn.md): 按所在地区与职业目标, 在 Claude Code, Codex, Antigravity 三款里锁定要学的那一款, 并把对应账号办好.

---

## 3. 上手一款工具

选定之后, 只读属于你的那一篇, 其余两篇直接跳过. 每款工具一篇长文, 从添加项目, 认识界面上每一个开关, 到让它读材料写文件, 再到用上第一个 Agent Skill, 全部讲透.

- [05-claude-code](../05-claude-code/README-cn.md): Claude Code Desktop 上手, 从选定文件夹到用上第一个 Agent Skill.
- [06-codex](../06-codex/README-cn.md): Codex Desktop 上手, 从添加项目到用上第一个 Agent Skill.
- [07-antigravity](../07-antigravity/README-cn.md): Antigravity 这一篇还没开放, 说明现状, 以及现在就想学的话该怎么先拿 Codex 篇当参照.

---

## 4. 用得更快

会用只是起点, 这一块讲的是那些一个人干出十倍效率的人, 到底在做什么不一样的事.

- [08-plan-and-delegate](../08-plan-and-delegate/README-cn.md): 做计划, 分任务, 同时带几个 session 干活的心法, 这套心法本质上也是团队管理能力.

---

## 5. 收尾, 拼成全景图

最后一篇是整门课的收尾. 它不教新东西, 只做回望与拔高两件事.

- [09-review-and-level-up](../09-review-and-level-up/README-cn.md): 梳理这类 Agent App 共有的八件事, 说清这门课停在哪儿以及想再往前该往哪走, 并把第 08 篇的心法接回来收尾.

---

## 6. 小结

这几块拼起来, 走的是一条完整的路: 先有骨架, 再做选择, 然后亲手用熟一款工具, 最后学会怎么用它用得快. 读完这条线, 你不只是学会了一款软件, 你学会的是这一整类 AI Agent App 的共同打法, 换任何一款新工具, 你都知道该先看什么, 怎么上手.
