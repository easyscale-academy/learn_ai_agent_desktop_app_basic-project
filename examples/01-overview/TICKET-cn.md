# 读完系列索引, 拿到整门课的地图

## 1. 目标

这个 Task 只有一件事: 花几分钟把整门课的地图看一遍, 心里清楚后面八篇分成哪几块, 每块解决什么, 该按什么顺序走. 没有产出物, 也没有要跑的命令, 但值得你认真读完再往下走, 否则你很容易在中间那几篇长文里迷失方向.

---

## 2. 要做的事情

1. 通读本 Task 的 README, 把这门课分成哪几块过一遍.
2. 记住上手一款工具那一块是三选一, 不是三篇都读; 具体选哪一篇, 由后面的选型那一篇帮你定下来.
3. 按编号顺序从下一个 Task 开始读.

**预计用时:** 3 到 5 分钟

---

## 3. 检查清单

- [ ] **说得出分块**: 你能说出这门课分成哪几块, 每块解决什么问题.
- [ ] **说得出起点**: 你能说出自己打算从哪一篇开始读, 以及为什么.
- [ ] **知道哪块是三选一**: 你能说出上手一款工具那一块里有三篇, 而你只需要读其中一篇, 另外两篇可以直接跳过.
