# learn_install_ai_agent_desktop_app-project

AI Agent 桌面应用, 也就是 Claude Code, Codex, Antigravity 这类工具, 正快速成为知识工作者的标配入口. 但对第一次接触的人来说, 账号注册, 网络环境, 订阅方案, CLI 与 Desktop App 的取舍, 处处是看不见的门槛. 装不对, 后面的学习和使用都无从谈起.

学完这门课, 你能根据自己的所在地区和职业目标, 独立完成一款主流 AI Agent 桌面应用的账号注册, 订阅开通, 本地安装, 并跑通第一个任务, 哪怕是零科技行业经验的用户也能顺利走完全程. 深度停留在 basic: 目标不是精通某个工具的高级用法, 而是能立刻拿它加速你的学习效率, 做事效率, 以及消化知识的能力.

选型上按现实处境分野. 长期在美国求学就业, 优先选 Claude Code, 它在美国企业里的采用规模和使用者口碑目前最强. 主要活动在中国大陆, 受 Claude 对该地区的限制, 可以在 Codex 与 Antigravity 之间二选一, 2026 年年中这个时间点, Codex 比 Antigravity 更成熟, 因而更推荐. 三款工具选你日常真正会用的那一款学即可, 不必全学.
