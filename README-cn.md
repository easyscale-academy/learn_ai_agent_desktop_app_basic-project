# learn_ai_agent_desktop_app_basic-project

AI Agent Desktop App, 也就是 Claude Code, Codex, Antigravity 这类工具, 正快速成为知识工作者的标配入口. 它和你熟悉的 ChatBot 不是一回事: 你交代一个目标, 它自己拆解步骤, 读你的文件, 改你的文件, 跑完再自己检查一遍. 但对第一次接触的人来说, 该选哪一款, 账号怎么办, 界面上一排按钮都是什么, 怎么才能真正让它干活而不只是聊天, 处处是看不见的门槛.

学完这门课, 你能按自己的处境选定一款工具并把它用熟: 让它替你读写文件与截图, 召唤一个全世界统一标准的 Agent Skill 把活干完, 看懂上下文这种资源是怎么被悄悄吃掉的, 并养成把重要结论落进文件的习惯. 更要紧的是, 你会拿到一套同时带几个 session 干活的做事方式: 先把事情想到七成, 再分头派出去, 自己回来当那个审阅进度的人. 这套手感换个场景就是团队管理能力的雏形. 深度停留在 basic 到能立刻拿它加速日常工作的中级手感, 不深入任何工具的专业自动化或系统级操作场景.

选型上按现实处境分野: 长期在美国求学就业的优先选 Claude Code, 它在美国企业里的采用规模和口碑目前最强; 主要活动在中国大陆的, 受 Claude 对该地区的限制, 在 Codex 与 Antigravity 之间二选一, 2026 年年中这个时间点 Codex 更成熟因而更推荐. 三款只需学你日常真正会用的那一款, 不必全学. 内容全部拆在 [examples/](examples/) 下, 打开它从 01 那篇索引开始按编号读下去即可, 不需要任何斜杠命令或额外的环境准备.
