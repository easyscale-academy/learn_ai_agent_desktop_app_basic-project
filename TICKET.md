# Complete the Learn to Use an AI Agent Desktop App Course

## 1. Goal

Finishing every Task in this course should leave you with a complete, immediately usable set of AI Agent Desktop App skills: knowing which tool to pick, getting your own account set up, recognizing every switch in the interface that actually matters, having it read and write files for you, putting an Agent Skill to work, and picking up a mindset for running several sessions at once, well past the level of occasionally asking it a one-off question. By the end you should also know where this course stops, and where to go if you want to push further.

---

## 2. Things to Do

1. Read the root README first, so you understand how this course is meant to be read.
2. Go into examples and read in numeric order starting at 01. The first piece gives you a map of the whole course.
3. Read each Task's README first, then work through its own TICKET item by item and confirm it.
4. When you reach the block covering specific tools, read only the piece for the tool you picked, and skip the other two.
5. Read the final wrap up Task, and get clear on what you've learned and where to go next.

**Estimated time:** 2 to 4 hours total, roughly 1 to 2 hours for picking a tool and getting your account set up, and another 1 to 2 hours for getting hands on with the tool and practicing the mindset

---

## 3. Checklist

- [ ] **Every Task done**: every Task's TICKET checklist under examples is checked off item by item.
- [ ] **Can reproduce it independently**: without looking back at the tutorial, you can walk through the core workflow (picking a tool, getting an account, working the interface, putting an Agent Skill to work) from scratch on your own.
- [ ] **Can explain the concepts**: you can explain, in your own words, the base model, ChatBot, Agent skeleton, and what each of the eight traits shared across this category of Agent App actually is.
- [ ] **Know where to go next**: you can name the directions available if you want to push further, and you know the most important one is reading the official docs with an AI beside you.

---

## 4. Key Abilities

- Explain the base model, ChatBot, Agent skeleton, and what you're actually paying for.
- Pick which of Claude Code, Codex, or Antigravity to learn based on your own region and career goals, and get a free account set up.
- Bind a working folder and GitHub Repo to an Agent App, set the permission mode to the level you want, and use its file explorer to confirm which files it actually touched.
- Hand material to the AI three ways, by screenshot, by file path, and by right-click attach, have it write output to a location you specify, and review the changes without leaving the app.
- Invoke an Agent Skill to get a task done, and understand it as a worldwide standard that works basically the same way no matter which tool you switch to.
- Understand the session, chat, and context memory model, know that what you can't see on screen eats context too, and use Fork to keep a clean context.
- Adjust model and Effort to match how hard a task actually is, and know which tier your money is going toward.
- Write your goal and steps into a plan document before starting, tell exploratory tasks apart from execution and review tasks, and run several sessions in parallel.
- Name the eight traits shared across this category of Agent App, so you already know what to look for the moment you pick up a new tool.
