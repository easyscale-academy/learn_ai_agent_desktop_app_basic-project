# Complete the Learn to Use an AI Agent Desktop App Course

## 1. Goal

Finishing every mini task in this course should leave you with a complete, immediately usable set of AI Agent Desktop App skills: knowing which tool to pick, getting your own account set up, recognizing every switch in the interface, having it read and write files for you, putting an Agent Skill to work, and picking up a mindset for running several sessions at once, well past the level of occasionally asking it a one-off question.

---

## 2. Things to Do

1. Read the root README first, so you understand how this course is meant to be read.
2. Read the series index under examples to get a map of the whole course.
3. Read every mini task under examples in numeric order, reading each one's README first, then working through its own TICKET item by item and confirming it.
4. Read the final review and level up article, and get clear on what you've learned and where to go next.

**Estimated time:** 6 to 10 hours, best split across a few sessions rather than done in one sitting

---

## 3. Checklist

- [ ] **Every mini task done**: every task's TICKET checklist under examples is checked off item by item.
- [ ] **Can reproduce it independently**: without looking back at the tutorial, you can walk through the core workflow (picking a tool, getting an account, working the interface, putting an Agent Skill to work) from scratch on your own.
- [ ] **Can explain the concepts**: you can explain, in your own words, the foundation model, ChatBot, Agent skeleton, and what each of the traits shared across this category of Agent App actually is.

---

## 4. Key Abilities

- Explain the foundation model, ChatBot, Agent skeleton, and what you're actually paying for.
- Pick which of Claude Code, Codex, or Antigravity to learn based on your own region and career goals, and get a free account set up.
- Bind a working folder and GitHub Repo to an Agent App, and use its file browser to confirm which files it actually touched.
- Hand material to the AI through screenshots, file paths, and similar means, have it write output to a location you specify, and review the changes without leaving the app.
- Invoke an Agent Skill to get a task done, and understand it as a worldwide standard that works basically the same way no matter which tool you switch to.
- Understand the session, chat, and context memory model, and use Fork to branch off from a point in the conversation without touching the original thread.
- Adjust model and Effort to match how hard a task actually is, and know which tier your money is going toward.
- Write your goal and steps into a plan document before starting, so you can pick right back up even if you lose the session.
- Tell exploratory tasks apart from execution and review tasks, and know when to think something through in sequence versus when you can run several sessions in parallel.
- Name the seven traits shared across this category of Agent App, so you already know what to look for the moment you pick up a new tool.
